# 校园网自动连接 · CampusNetAutoConnect

作者：**尘遂** ｜ 版本 1.8.0

一个为校园网认证页量身定做的自动连接小工具：填一次账号密码，之后开机自动帮你连上。
界面采用 **Neumorphism（新拟物派）** 风格 —— 浅色单色系 + 双光源柔光，明暗双主题随环境切换。

---

## 〇、怎么拿到能直接跑的程序

这个仓库里放的是**源码**，不含编译产物。想直接用的话有两条路：

| 你的情况 | 怎么做 |
|---|---|
| 只想用，不想折腾 | 到本仓库的 **Releases** 页下载打包好的压缩包，解压后双击 `校园网自动连接.exe` **免安装** |
| 想自己改 | 见下面的「五、目录结构 → 开发环境运行」 |

> 打包产物约 293 MB（其中内嵌浏览器内核占 195 MB，这是能自动填表的前提），
> 压缩后约 121 MB。整个文件夹要一起拷走，**不能只拿那一个 exe**。

## 一、界面结构

| 标签页 | 干什么用的 |
|---|---|
| **连接** | 填认证页地址、账号、密码；立即连接 / 测试 / 诊断 / 停止后台（内容可上下滑动） |
| **预览** | 认证页**整页全屏**展示，自动填表就发生在这里；还能「设为认证页」、「刷新」、「后退」、「截图」 |
| **外观** | 明暗主题、自定义网页背景（上传图片、暗化、模糊、填充方式） |
| **高级** | 开机自启、网络触发、后台守护、联网检测、表单兜底选择器 |
| **日志** | 每一步的完整记录，可清空 / 导出 / 打开目录 |
| **关于** | 作者与功能说明 |

> **启动很快就绪**：窗口几乎秒开。内置浏览器是在你**第一次需要它**的时候才启动的
> （点【立即连接】/【打开认证页】，或切到【预览】页），首次约 1 秒，状态栏会提示
> "正在启动内置浏览器…"，之后就一直是热启动。

## 二、它能做什么

### 基础
| 功能 | 说明 |
|---|---|
| 本地加密存储 | 账号、密码、认证页地址存在 `%APPDATA%\CampusNetAutoConnect\config.json`，密码用 **Windows DPAPI** 加密 |
| 开机自启动 | 写入注册表 Run 项，可随时开关 |
| 自动打开认证页 | 内置浏览器加载认证地址，预览页全屏可见 |
| 自动填表并登录 | 自动识别用户名框 / 密码框 / 登录按钮，填好后点击提交 |
| 智能地址兜底 | 就算填错成「认证成功页」，也会自动找到真正的登录页 |
| 测试连接 | 完整跑一遍登录流程，并弹出逐步报告 |
| 诊断页面 | 只识别不提交，列出页面表单结构 |
| 停止后台 | 一键停掉后台守护与当前流程 |

### 进阶
| 功能 | 说明 |
|---|---|
| 网络触发 | **连上指定 Wi-Fi 后自动认证**（解决"开机时 WiFi 还没连上、认证页打不开"） |
| 后台守护 | 每隔 N 秒检查网络，掉线自动重连 |
| 多探测点 | 内置 4 个探测地址，任意一个通就算在线，避免误判 |
| 自定义网页背景 | 上传图片替换认证页背景，可调暗化、模糊、填充方式 |
| 明暗双主题 | 深色 / 浅色 / 跟随系统，头部按钮一键轮换 |
| 表单兜底 | 自动识别失败时可手填 CSS 选择器 |
| 验证码处理 | 检测到验证码会提示你手动输入，之后自动复查结果 |
| 失败自动截图 | 连不上时自动存一张页面截图，方便定位 |

## 三、连不上怎么办（先看这里）

### ⚠️ 最常见的原因：认证页地址填错了

**要填的是「登录页」——那个有账号密码输入框的页面**，不是登录成功后的页面。

登录页和成功页长得像但不一样，看地址栏就知道：

| 地址长这样 | 是什么 | 能不能用 |
|---|---|---|
| `http://10.10.10.1/srun_portal_pc?ac_id=1&theme=pro` | 登录页（深澜） | ✅ 用这个 |
| `http://10.10.10.1/srun_portal_success?ac_id=1&theme=pro` | **认证成功页** | ❌ 这页没有输入框 |
| `http://10.10.10.1` | 认证网关 | ✅ 一般会自动跳到登录页 |

**怎么找到正确的地址**：在浏览器里先断开 / 退出登录，然后随便打开一个网站，被跳转到的那个页面就是登录页，把它的地址复制过来。

> 就算填错了也没关系：程序会自动尝试把 `_success` 换成登录页、退到站点根目录、
> 以及靠网关劫持重定向，一般能自己救回来。找到真正能登录的地址后，
> 到【预览】页点一下 **【设为认证页】**，下次就不用绕路了。

### 其他排查顺序

1. **看【日志】页，一键【复制全部】发给开发者** —— 每一步都有记录（现在已经会同时写进
   `%APPDATA%\CampusNetAutoConnect\logs\日期.log`，关掉程序也还在）
2. **点【诊断页面】** —— 会列出识别到的表单、密码框、按钮；密码框一栏空的就是没找对页面
3. **手动指定选择器** —— 【高级】→【表单兜底】，选择器可以在浏览器里按 F12 对元素右键 → 复制 → 复制 selector
4. **有验证码** —— 程序会提示你手动输入，输完点登录，它会自己复查结果
5. **页面白屏 / 加载失败** —— 确认【高级】里「浏览器兼容模式」是开的（默认开）
6. **自动触发失败、但你手动点一下就成功** —— 这是页面渲染慢导致的：
   认证页是单页应用，刚打开时可能还停在「单点登录 / 扫码」模式，
   账号登录按钮还没渲染出来。v1.5.0 起程序会等它切换好再点，
   而且**绝不会去点「单点登录」这类模式切换按钮**（那个点了等于没登录）。
   日志里会写「页面还停在「单点登录 / 扫码」这类模式，等它切到账号登录，稍后再试」

### 程序是怎么判断"连上了"的（v1.2.0 重写）

按可靠性从高到低，命中任意一条就算成功：

1. **页面自己说已登录** —— 地址跳到 `xxx_success`，或页面上出现「注销 / 已用流量」
2. **网络探测通过** —— 4 个探测地址任意一个通
3. 打开页面时如果发现**已经是登录状态**，直接算成功，不再瞎折腾

> 以前只看第 2 条，而校园网里探测地址经常不通，于是会出现「明明登上去了，程序却说失败」。
> 现在以页面状态为准，不会再误报。

## 三·五、开机自动连不上？用「网络触发」

**问题**：校园网要先连上 Wi-Fi，才能打开认证页。开机时 Wi-Fi 往往还在连、DHCP 还没拿到地址，
这时候去打开认证页必然失败。

**解决**：程序每几秒看一眼当前连的是哪个无线网络，**一旦连上你指定的那个，立刻自动去认证**。

在【高级】→【网络触发】里设置：

| 项 | 说明 |
|---|---|
| 连上指定无线网络后自动认证 | 总开关 |
| 无线网络名 | 填你的校园网 Wi-Fi 名（如 `CampusWiFi`）；点【用当前】一键填入当前连着的那个；**留空 = 任意无线网络** |
| 检查间隔 | 几秒检查一次，默认 4 秒 |
| 连上后等待 | 刚连上时 DHCP 可能还没就绪，等几秒再认证，默认 3 秒 |
| 当前 | 实时显示现在连的 Wi-Fi 和信号强度 |

工作方式（两条路都会触发，谁先到算谁）：

1. **刚连上网络** → 立刻排一次认证
   开机 → 程序随系统启动（Wi-Fi 还没连上，保持安静）→ 你连上 CampusWiFi → 检测到 → 自动认证

2. **网络名没变、但其实上不了网** → 也会触发
   每 15 秒复查一次网络是不是真能上网；不通就认证。
   （这一条是给"手动断开又连上"准备的：动作太快时程序看不出网络名变过，
   但只要上不了网就会被抓到。触发后有 30 秒冷却，不会反复折腾。）

3. 之后如果掉线，还有【后台守护】兜底

> 如果是插网线的台式机（没有无线网卡），这块会自动禁用，用【后台守护】就够了。

## 三·六、换到别的学校 / 别的运营商怎么用

程序本身是通用的：它不认学校、不认运营商，只认「页面上有没有账号密码框」。
换环境时**要改的只有三样东西**：

| 改什么 | 在哪改 | 怎么找 |
|---|---|---|
| **认证页地址** | 【连接】页第一行 | 先断开认证，然后随便打开一个网站，被跳转到的那个页面就是。复制地址栏 |
| **无线网络名** | 【高级】→【网络触发】 | 连上校园网 Wi-Fi，点【用当前】一键填入 |
| **运营商** | 【高级】→【表单兜底】 | **只有 portal 要求选运营商时才需要**，填中文名即可（如 `电信`），留空就按页面默认 |

### 关于运营商（重点）

多运营商的学校，portal 上会有一个"联通 / 电信 / 移动"的下拉框。程序会自动把它选成你填的那个。

- 填中文名就行（`电信`），程序会自己去匹配下拉框里的选项，不用管它是 `@telecom` 还是 `1`
- 不填的话，就用页面自己的默认值——**默认很可能不是你的运营商**，所以该填还是要填
- 不确定有哪些可选？点【诊断页面】，日志里会列出这个下拉框的全部选项：

```
运营商选择框：select，当前值='@unicom'
  可选：@unicom = 联通
  可选：@telecom = 电信
  可选：@cmcc = 移动
```

### 有些学校的账号要带后缀

比如账号必须写成 `20250001@telecom`。这种情况**直接把后缀一起填进【账号】框**就行，
程序会原样发送、不做任何加工。

### 不同 portal 系统的适配情况

| 认证系统 | 地址特征 | 支持情况 |
|---|---|---|
| 深澜 Srun | 含 `srun_portal` | ✅ 充分验证过（含单点登录模式、运营商选择） |
| 城市热点 Dr.COM | 跳转到 `xxx/portal` | ✅ 靠通用识别 + 网关劫持兜底 |
| 锐捷 Ruijie | `eportal` / `a79.htm` | ✅ 靠通用识别 |
| 华为 / H3C | 302 跳到认证页 | ✅ 靠通用识别 |
| 802.1X 客户端认证 | **没有网页** | ❌ 这类不走网页，程序帮不上忙 |

### 到了新环境，按这个顺序验证

1. 填好三项 → 点【保存配置】
2. 点【诊断页面】→ 日志里应该能看到密码框、登录按钮；如果密码框是空的，说明地址不对
3. 顺便瞄一眼日志里的「运营商选择框」那行，确认要不要填运营商
4. 点【测试连接】跑一遍完整流程，会弹报告告诉你每一步的结果

> 万一自动识别不出来，【高级】→【表单兜底】里可以手填三个 CSS 选择器
> （浏览器里按 F12 对着元素右键 → 复制 → 复制 selector）。

## 四、安全说明

- 密码经 Windows DPAPI 加密后落盘，密钥绑定当前 Windows 账户：**换账户、换电脑都解不开**
- 配置文件只在 `%APPDATA%\CampusNetAutoConnect\` 下，不联网上传任何东西
- 网络探测走的是明文 HTTP 请求（和浏览器打开网页一样），不涉及额外权限
- 唯一会写系统的地方是注册表的自启动项，关掉开关就会删除

## 六、关于界面风格

新拟物派的核心是**用双光源阴影模拟光线打在类黏土表面**：

- 光源方向恒定：**左上为高光，右下为暗影**，任何控件都不破例
- 元素与背景同色系，靠阴影区分层次，不使用描边
- 凸起 = 可点击；凹陷 = 已按下 / 输入区
- 悬停时阴影**缩小**（手指靠近遮光），按下时从凸起**转为凹陷**，全程不位移
- 输入框默认深凹陷，聚焦时凹陷变浅（通道打开）

因为 Qt 的 QSS 不支持 `box-shadow`，这些效果全部由 `ui/neumorphism.py` 用 QPainter
逐层绘制同心环带近似高斯弥散实现，并缓存成位图，保证滚动时不掉帧。
